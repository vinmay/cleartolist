How we handle photos

Your photos are checked to be real JPEG, PNG or WebP images, then re-encoded, which removes all metadata, including GPS location. They're used for this one scan by a self-hosted GPU worker running open models, kept in memory only, and deleted as soon as the scan finishes. If the scanner is busy, they're deleted anyway after eight minutes at most. The text result is kept for ten minutes so this page can show it. We keep anonymous counts of scans, never photos, filenames or addresses.
